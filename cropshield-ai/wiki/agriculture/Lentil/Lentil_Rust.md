# Lentil Rust

## Diagnostic Phenotype

### Primary Affected Plant Parts

-   leaf_blade
-   petiole
-   stem
-   whole_plant

### Symptom Class

-   rust_pustules
-   discrete_lesions
-   necrotic_spots

### Lesion / Symptom Geometry

-   Primary shape: `circular_to_oval_pustules`
-   Elongation: `low`
-   Width profile: `slightly_wider_at_center`
-   Ends: `rounded`
-   Discrete or continuous: `discrete_to_coalescing`

### Size

-   small discrete pustules that may increase in number and occasionally
    coalesce as disease severity increases

### Color

-   Center / primary color: orange, orange_brown, reddish_brown
-   Margin: orange_brown, reddish_brown
-   Surrounding tissue: green
-   Color transition: `sharp`
-   Current/overall colors: orange, orange_brown, reddish_brown, brown,
    green

### Texture

-   Current texture: raised, rough, powdery, pustular, dry_in_late_stage
-   Early appearance: `small_pale_orange_to_yellowish_spots`

### Pattern and Distribution

-   Orientation: `irregular`
-   Distribution: `discrete_scattered`
-   Coalescence: `low_to_moderate`
-   Vein relationship: `crosses_or_ignores_veins`

### Spatial Location

-   Primary location:
    `leaf_blade_with_possible_petioles_and_stem_involvement`

### Whole-Plant / Field-Level Features

-   numerous_orange_brown_pustules
-   scattered_leaf_pustules
-   progressive_leaf_discoloration
-   premature_leaf_drying
-   reduced_green_leaf_area
-   severe_defoliation_in_advanced_cases

## Hallmark Features

-   small_raised_orange_to_reddish_brown_pustules
-   powdery_spore_surface
-   discrete_scattered_distribution
-   predominantly_foliar_occurrence
-   increasing_pustule_density_with_disease_progression

## Negative / Exclusion Features

These features should reduce confidence in this diagnosis when they are
clearly present.

-   diffuse_whole_plant_wilting_without_pustules
-   white_powdery_surface_growth
-   large_circular_necrotic_lesions
-   soft_root_rot
-   bright_yellow_green_mosaic_pattern

## Differential Diagnosis

### Similar Problems

-   Lentil Wilt
-   Lentil Powdery Mildew
-   Other Fungal Leaf Spots
-   Nutrient Deficiency

### Diagnostic Discriminators

-   Look for raised pustules rather than flat necrotic spots.
-   Compare orange to reddish-brown pustule color with white powdery
    growth.
-   Distinguish discrete rust pustules from diffuse whole-plant wilting.
-   Compare surface texture and relief before interpreting color alone.
-   Treat uncertainty in pustule structure as uncertainty, not as a
    fact.
