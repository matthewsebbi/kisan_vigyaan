# Chickpea Dry Root Rot

## Diagnostic Phenotype

### Primary Affected Plant Parts

-   root
-   collar
-   lower_stem
-   whole_plant

### Symptom Class

-   root_rot
-   necrotic_lesions
-   plant_wilting

### Lesion / Symptom Geometry

-   Primary shape: `irregular_root_and_collar_lesions`
-   Elongation: `moderate_along_root_and_lower_stem`
-   Width profile: `variable`
-   Ends: `irregular`
-   Discrete or continuous: `discrete_to_coalescing`

### Size

-   lesions may occur on individual roots and progressively extend over
    larger portions of the root system and lower stem

### Color

-   Center / primary color: brown, dark_brown, blackish_brown
-   Margin: dark_brown
-   Surrounding tissue: pale_brown_to_healthy_tissue
-   Color transition: `sharp_to_gradual`
-   Current/overall colors: brown, dark_brown, blackish_brown,
    straw_brown

### Texture

-   Current texture: dry, brittle, woody, shriveled, necrotic
-   Early appearance: `root_tissue_discoloration_and_drying`

### Pattern and Distribution

-   Orientation: `longitudinal`
-   Distribution: `root_system_and_lower_stem`
-   Coalescence: `moderate_to_extensive`
-   Vein relationship: `not_applicable`

### Spatial Location

-   Primary location: `roots_and_lower_stem`

### Whole-Plant / Field-Level Features

-   sudden_or_progressive_wilting
-   leaf_yellowing
-   premature_leaf_drying
-   root_shriveling
-   reduced_plant_vigor
-   plant_death_in_severe_cases
-   patchy_field_occurrence

## Hallmark Features

-   dry_shriveled_root_tissue
-   brown_to_dark_brown_root_discoloration
-   brittle_necrotic_roots
-   progressive_wilting
-   root_system_decline_without_soft_water_soaked_decay

## Negative / Exclusion Features

These features should reduce confidence in this diagnosis when they are
clearly present.

-   soft_water_soaked_root_tissue
-   extensive_mushy_collar_rot
-   primary_vascular_browning_without_root_decay
-   white_powdery_leaf_growth
-   discrete_circular_leaf_spots

## Differential Diagnosis

### Similar Problems

-   Chickpea Fusarium Wilt
-   Chickpea Wet Root Rot
-   Collar Rot
-   Other Chickpea Root Rots

### Diagnostic Discriminators

-   Compare dry brittle root decay with soft or water-soaked root rot.
-   Inspect the root and collar tissues before interpreting above-ground
    wilting.
-   Distinguish external root necrosis from vascular discoloration
    inside the stem.
-   Compare tissue consistency, especially dry and brittle versus soft
    and water-soaked.
-   Treat uncertainty in root texture or internal vascular discoloration
    as uncertainty, not as a fact.
