# Wheat Flag Smut

## Diagnostic Phenotype

### Primary Affected Plant Parts

-   leaf_blade
-   leaf_sheath
-   stem
-   whole_plant

### Symptom Class

-   elongated_smut_lesions
-   leaf_striping
-   tissue_discoloration

### Lesion / Symptom Geometry

-   Primary shape: `longitudinal_linear_streaks`
-   Elongation: `high_at_leaf_level`
-   Width profile: `narrow_and_uniform`
-   Ends: `pointed_tapered`
-   Discrete or continuous: `continuous_or_coalescing`

### Size

-   long, narrow dark streaks extending longitudinally along leaves and
    leaf sheaths; affected areas may occupy substantial portions of the
    leaf surface

### Color

-   Center / primary color: black, dark_gray, dark_brown
-   Margin: gray_brown, yellow_green
-   Surrounding tissue: green
-   Color transition: `sharp_two_tone`
-   Current/overall colors: black, dark_gray, dark_brown, yellow_green

### Texture

-   Current texture: raised, rough, powdery, brittle
-   Early appearance: `elongated_pale_to_dark_streaks`

### Pattern and Distribution

-   Orientation: longitudinal
-   Distribution: continuous_linear_streaks
-   Coalescence: extensive
-   Vein relationship: parallel_to_leaf_axis_and_veins

### Spatial Location

-   Primary location: leaf_blade_and_leaf_sheath

### Whole-Plant / Field-Level Features

-   dark_longitudinal_leaf_streaks
-   elongated_smut_bands
-   leaf_distortion_or_splitting_in_severe_infection
-   reduced_leaf_area
-   localized_stem_or_sheath_symptoms

## Hallmark Features

-   long_dark_longitudinal_streaks
-   black_to_dark_smut_material
-   leaf_and_sheath_dominant_symptoms
-   linear_banded_pattern
-   powdery_or_rough_smut_surface

## Negative / Exclusion Features

These features should reduce confidence in this diagnosis when they are
clearly present.

-   bright_yellow_pustules_in_narrow_rows
-   scattered_orange_brown_leaf_pustules
-   black_pustules_dominantly_on_stems
-   white_powdery_surface_growth
-   large_irregular_tan_or_brown_leaf_lesions

## Differential Diagnosis

### Similar Problems

-   Wheat Stripe / Yellow Rust
-   Wheat Leaf / Brown Rust
-   Wheat Stem / Black Rust
-   Wheat Leaf Blight
-   Wheat Powdery Mildew

### Diagnostic Discriminators

-   Compare the lesion geometry before interpreting the dark color.
-   Distinguish long dark smut streaks from raised rust pustules
    arranged in rows.
-   Compare the surface texture to separate powdery smut material from
    rust pustules or superficial mildew growth.
-   Check whether symptoms are strongly longitudinal and band-like.
-   Treat uncertainty in streak extent, surface texture, or plant-part
    involvement as uncertainty rather than as a fact.
