# Cotton Leaf Curl Disease

## Diagnostic Phenotype

### Primary Affected Plant Parts

- leaf_blade
- leaf_veins
- growing_point
- whole_plant

### Symptom Class

- leaf_curling_and_distortion
- vein_thickening
- enation_outgrowth

### Lesion / Symptom Geometry

- Primary shape: `upward_or_downward_leaf_curling_with_cup_like_outgrowths`
- Elongation: `along_leaf_veins`
- Width profile: `thickened`
- Ends: `not_applicable`
- Discrete or continuous: `continuous_along_minor_and_major_veins`

### Size

- Spreads systemically across entire upper canopy and young growing shoots.

### Color

- Center / primary color: dark_green_thickened_veins_with_interveinal_chlorosis
- Margin: green
- Surrounding tissue: pale_green_to_yellowish
- Color transition: `gradual`
- Current/overall colors: dark_green, pale_green, yellow, chlorotic_yellow

### Texture

- Current texture: leathery_thickened_brittle_puckered_wrinkled
- Early appearance: `thickening_of_small_veins_on_underside_of_young_leaves`

### Pattern and Distribution

- Orientation: `vein_centered_thickening`
- Distribution: `young_top_leaves_and_apical_shoots`
- Coalescence: `extensive`
- Vein relationship: `vein_bound_thickening`

### Spatial Location

- Primary location: `underside_of_upper_young_leaves`

### Whole-Plant / Field-Level Features

- upward_or_downward_curling_of_leaf_margins
- dark_green_thickening_of_main_and_secondary_veins
- cup_like_leaf_outgrowths_enations_on_underside_of_leaves
- severe_plant_stunting_and_bushy_appearance
- drastic_reduction_in_boll_formation_and_size

## Hallmark Features

- upward_and_downward_leaf_margin_curling
- vein_thickening_swelling_on_underside_of_leaves
- presence_of_leaf_like_enations_foliar_outgrowths_on_veins

## Negative / Exclusion Features

These features should reduce confidence in this diagnosis when they are clearly present.

- dark_necrotic_sunken_boll_spots
- internal_stem_vascular_ring_blackening
- shredded_root_bark
- water_soaked_angular_leaf_lesions

## Differential Diagnosis

### Similar Problems

- Herbicide Damage (2,4-D drift causing leaf strapping)
- Aphids / Thrips feeding injury
- Cotton Mosaic Virus

### Diagnostic Discriminators

- CLCuD uniquely features true leaf-like outgrowths (enations) and prominent vein thickening on the lower leaf surface.
- Sucking pest damage causes leaf curling but lacks the structured enations and vein swelling produced by Begomovirus infection.

## Environmental Conditions

### Temperature

- 30°C - 40°C (High temperatures favor vector *Bemisia tabaci* multiplication)

### Humidity

- Moderate humidity supporting whitefly vector populations.

### Rainfall / Moisture

- Dry weather following rain promotes whitefly population surges.

### Soil

- Not directly soil-dependent; spread exclusively via insect vector (*Bemisia tabaci*).

## Crop Stage

- Vegetative phase to early flowering phase (young tissue highly susceptible)
