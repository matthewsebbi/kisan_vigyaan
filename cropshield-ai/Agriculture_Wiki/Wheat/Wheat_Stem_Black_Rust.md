# Wheat Stem / Black Rust

## Diagnostic Phenotype

### Primary Affected Plant Parts

-   stem
-   leaf_sheath
-   leaf_blade
-   whole_plant

### Symptom Class

-   discrete_pustules
-   stem_lesions

### Lesion / Symptom Geometry

-   Primary shape: `elongated_oval_pustules`
-   Elongation: `high`
-   Width profile: `wider_at_center`
-   Ends: `blunt_rounded_to_irregular`
-   Discrete or continuous: `discrete_scattered_to_coalescing`

### Size

-   elongated pustules several millimetres long, often larger and more
    conspicuous than typical leaf-rust pustules; may occur in clusters
    on stems and leaf sheaths

### Color

-   Center / primary color: reddish_brown, dark_brown, black
-   Margin: reddish_brown, dark_brown
-   Surrounding tissue: green_to_normal_stem_tissue
-   Color transition: `sharp_two_tone`
-   Current/overall colors: reddish_brown, dark_brown, black,
    blackish_brown

### Texture

-   Current texture: raised, rough, powdery, later_dark_and_persistent
-   Early appearance: `small_reddish_brown_raised_spots`

### Pattern and Distribution

-   Orientation: longitudinal
-   Distribution: discrete_scattered_on_stems_and_sheaths
-   Coalescence: moderate_to_extensive
-   Vein relationship: not_applicable_on_stem

### Spatial Location

-   Primary location: stem_and_leaf_sheath

### Whole-Plant / Field-Level Features

-   elongated_dark_pustules_on_stems
-   reddish_brown_to_black_raised_lesions
-   pustules_on_leaf_sheaths
-   localized_stem_surface_discoloration
-   severe_infection_may_reduce_stem_vigor

## Hallmark Features

-   elongated_raised_pustules_on_stems
-   reddish_brown_to_dark_brown_or_black_color
-   stem_and_leaf_sheath_dominant_distribution
-   rough_powdery_surface
-   larger_more_elongated_pustules_than_typical_leaf_rust

## Negative / Exclusion Features

These features should reduce confidence in this diagnosis when they are
clearly present.

-   bright_yellow_pustules_in_longitudinal_leaf_stripes
-   predominantly_scattered_orange_brown_leaf_pustules
-   large_flat_leaf_necrotic_lesions
-   continuous_uniform_leaf_yellowing_without_pustules

## Differential Diagnosis

### Similar Problems

-   Wheat Stripe / Yellow Rust
-   Wheat Leaf / Brown Rust
-   Stem lesions from other fungal diseases
-   Mechanical stem injury

### Diagnostic Discriminators

-   Compare the primary affected plant part before interpreting rust
    color.
-   Distinguish stem-dominant elongated pustules from leaf-dominant rust
    symptoms.
-   Compare pustule color and surface elevation rather than color words
    alone.
-   Check whether lesions are elongated and concentrated on stems or
    leaf sheaths.
-   Treat uncertain stem-lesion identification or pustule color as
    uncertainty rather than as a fact.
