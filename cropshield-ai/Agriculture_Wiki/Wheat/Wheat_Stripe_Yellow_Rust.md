# Wheat Stripe / Yellow Rust

## Diagnostic Phenotype

### Primary Affected Plant Parts

-   leaf_blade
-   leaf_sheath
-   whole_plant

### Symptom Class

-   discrete_pustules
-   chlorotic_striping

### Lesion / Symptom Geometry

-   Primary shape: `oval_circular_to_elongated_pustules`
-   Elongation: `moderate_to_high_at_leaf_level`
-   Width profile: `narrow_and_uniform`
-   Ends: `rounded_or_tapered`
-   Discrete or continuous: `discrete_in_rows`

### Size

-   small, narrow pustules arranged in elongated linear bands;
    individual pustules may be only a few millimetres long

### Color

-   Center / primary color: yellow, bright_yellow, orange_yellow
-   Margin: yellow_green_to_green
-   Surrounding tissue: green
-   Color transition: `sharp_to_gradual`
-   Current/overall colors: yellow, bright_yellow, orange_yellow,
    yellow_green

### Texture

-   Current texture: raised, rough, powdery
-   Early appearance: `small_pale_yellow_spots`

### Pattern and Distribution

-   Orientation: longitudinal
-   Distribution: discrete_linear_rows_or_stripes
-   Coalescence: limited_to_extensive_in_heavy_infection
-   Vein relationship: follows_leaf_axis_and_often_parallel_to_veins

### Spatial Location

-   Primary location: leaf_blade_with_longitudinal_rows_of_pustules

### Whole-Plant / Field-Level Features

-   yellow_striping_on_leaves
-   numerous_linear_rows_of_yellow_pustules
-   progressive_leaf_yellowing
-   reduced_green_leaf_area_in_severe_infection

## Hallmark Features

-   bright_yellow_to_orange_yellow_pustules
-   narrow_linear_rows
-   longitudinal_striping
-   pustules_concentrated_along_leaf_axes
-   powdery_raised_surface

## Negative / Exclusion Features

These features should reduce confidence in this diagnosis when they are
clearly present.

-   predominantly_brown_or_reddish_brown_pustules
-   predominantly_black_stem_pustules
-   large_irregular_necrotic_leaf_lesions
-   continuous_uniform_yellowing_without_pustules

## Differential Diagnosis

### Similar Problems

-   Wheat Leaf / Brown Rust
-   Wheat Stem / Black Rust
-   Septoria Leaf Blotch
-   Powdery Mildew

### Diagnostic Discriminators

-   Compare pustule color before interpreting the stripe pattern.
-   Compare whether pustules occur in narrow longitudinal rows or are
    scattered randomly.
-   Distinguish yellow-orange pustules from orange-brown or
    reddish-brown rust pustules.
-   Distinguish leaf-dominant striping from stem-dominant black rust
    symptoms.
-   Treat uncertain pustule arrangement or color as uncertainty rather
    than as a fact.
