# Wheat Leaf Blight

## Diagnostic Phenotype

### Primary Affected Plant Parts

-   leaf_blade
-   leaf_sheath
-   whole_plant

### Symptom Class

-   necrotic_lesions
-   leaf_blight
-   tissue_discoloration

### Lesion / Symptom Geometry

-   Primary shape: `elongated_irregular_lesions`
-   Elongation: `high_at_leaf_level`
-   Width profile: `variable_and_widening`
-   Ends: `irregular_to_tapered`
-   Discrete or continuous: `discrete_to_coalescing`

### Size

-   lesions may begin as small discolored spots and enlarge into
    elongated irregular necrotic areas covering substantial portions of
    the leaf

### Color

-   Center / primary color: tan, straw_colored, brown, reddish_brown
-   Margin: dark_brown, reddish_brown, yellow_brown
-   Surrounding tissue: green
-   Color transition: `gradual_to_sharp`
-   Current/overall colors: tan, straw_colored, brown, reddish_brown,
    dark_brown, yellow_brown

### Texture

-   Current texture: dry_papery, rough, brittle_in_severe_stage
-   Early appearance: `small_water_soaked_or_pale_spots`

### Pattern and Distribution

-   Orientation: longitudinal
-   Distribution: elongated_irregular_lesions
-   Coalescence: moderate_to_extensive
-   Vein relationship: follows_leaf_axis_and_may_cross_veins

### Spatial Location

-   Primary location: leaf_blade

### Whole-Plant / Field-Level Features

-   progressive_leaf_necrosis
-   expanding_elongated_lesions
-   lesion_coalescence
-   extensive_leaf_blight
-   reduced_green_leaf_area
-   premature_leaf_drying_in_severe_infection

## Hallmark Features

-   elongated_irregular_leaf_lesions
-   tan_to_brown_necrotic_centers
-   darker_brown_margins
-   progressive_coalescence
-   extensive_loss_of_green_leaf_area

## Negative / Exclusion Features

These features should reduce confidence in this diagnosis when they are
clearly present.

-   bright_yellow_pustules_in_longitudinal_rows
-   scattered_raised_orange_brown_pustules
-   black_smut_streaks_with_powdery_material
-   white_powdery_surface_growth
-   uniform_leaf_yellowing_without_necrotic_lesions

## Differential Diagnosis

### Similar Problems

-   Wheat Stripe / Yellow Rust
-   Wheat Leaf / Brown Rust
-   Wheat Stem / Black Rust
-   Wheat Flag Smut
-   Wheat Powdery Mildew
-   Septoria Leaf Blotch

### Diagnostic Discriminators

-   Compare lesion geometry before treating an elongated symptom as a
    rust stripe.
-   Compare center-to-margin color relationships rather than color words
    in isolation.
-   Distinguish flat necrotic lesions from raised powdery pustules.
-   Compare the distribution and degree of lesion coalescence.
-   Check whether the symptom is a blight pattern rather than a
    superficial fungal growth.
-   Treat uncertainty in lesion boundaries or vein relationship as
    uncertainty rather than as a fact.
